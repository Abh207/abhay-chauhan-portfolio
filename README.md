# Abhay Chauhan — Developer Portfolio

A production-oriented developer portfolio built with HTML5, CSS3, Vanilla JavaScript ES6+ and Vite.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Customize

- `src/data/projects.json` — projects
- `src/data/skills.json` — skills
- `src/data/journey.json` — learning journey
- `src/css/themes.css` — colors/themes
- `src/js/contact.js` — connect a real form/email endpoint
- Replace placeholder GitHub, LinkedIn, email and resume links in `index.html`.
